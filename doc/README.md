## 问题收录约定（每次问答必归档）

你问过的每个问题都会**同步收录**，按类型去三个地方之一：

| 问题类型 | 收录到 | 例子 |
|---|---|---|
| 代码/概念类（"XX 是干嘛的/为什么"） | `doc-code/对应域/设计说明.md` 的 Q&A | "CLI 用在何处" → doc-code/cli/设计说明.md Q4 |
| 踩坑/报错类（"遇到 XX 错误"） | `doc-dev/06-问题日志/问题日志.md`（P-XXX） | 当前记录至 P-023 |
| 接手/全局类（"项目现状/下一步"） | `doc-dev/00-快速上手/AI接管指南.md` | 当前状态速览 |

> 收录规则：**问题发生当天收录**，Q&A 标注日期；新问题编号顺延（Q5/Q6…、P-012…）。
> 这样文档跟着你的学习一起长大——换 AI 接手也能看到你问过的一切。
