# M3 —— 记忆沉淀 + 知识库检索

> **一句话目标**：让 Agent 从"会调工具"升级到"会记住 + 会查资料"——
>
> 1. **记忆沉淀**：对话中的用户事实被沉淀入库（跨会话记住）；
> 2. **知识检索**：文档分块向量化后可检索（Agent 引用检索结果回答）；
> 3. **向量模型可切换**：云端/本地可切换。
>
> **前置**：M2 验收 5/5 已过（工具目录 + 5 工具 + 2 中间件 + 流式）。

## 1. M3 做什么（用户视角）

| 能力 | 之前（M2） | 之后（M3） |
|---|---|---|
| 记住用户 | 无（每次都是新会话） | **跨会话记住**：说一次"我叫小王"新会话也记得 |
| 知识库 | knowledge 工具是占位（返回"未接入"） | **真检索**：分块 → 向量化 → 相似度召回，Agent 引用回答 |
| 向量模型 | 无 | 云端/本地可切换（配置驱动，代码不动） |
| 技能提示 | 无 | SKILL.md 发现 + 注入 prompt（骨架） |

## 4. 分步实施（每步有验收小点）

### Step 1：配置层
- `ModelConfig` 加 `embedding` 字段；`models_yaml` 解析 embedding 段；config.yaml 加 `models.embedding`
- 自测：`load_models_from_yaml` 能取到 embedding 配置

### Step 2：持久化层
- `schema.py` 加 3 张表（memories / knowledge_docs / knowledge_chunks）
- `memory_repositories.py`（create/recall/count）
- `knowledge_repositories.py`（create_doc/add_chunk/list_docs/all_chunks）
- `BaseRepository` 支持 db_path 线程本地连接（P-018 预案）
- 自测：init_db 后三张表可写可读

### Step 3：knowledge 域
- `chunker.py`：段落切分 + overlap + token 启发式
- `embedding/base.py` + `registry.py`：云端/本地 provider + 已知维度表 + 探针
- `service.py`：create_doc（分块→向量→落库）+ search（余弦 top_k）
- 自测：建库 1 文档 → 检索能召回相似块

### Step 4：memory 域
- `consolidate.py`：extract_facts（中文句式规则 + 疑问句过滤）
- `facade.py`：remember / recall（跨会话）/ count
- 自测：`extract_facts("我叫小王，喜欢爬虫")` 两条；疑问句不沉淀

### Step 5：skills 域
- `loader.py`：扫描 SKILL.md → frontmatter（name/description）→ build_skills_prompt
- 自测：无 skills 目录返回空串

### Step 6：接入 CLI + 工具
- `knowledge_tool`：占位 → 真检索（模块级句柄 configure_knowledge_service）
- `prompt.py`：build_lead_agent_system_prompt 加 memory_context / skills_context
- `cli/main.py`：装配记忆/知识 + 对话后沉淀 + 启动信息加记忆/知识条数
- 自测：对话"我叫小王" → memories 表 +1；新会话启动显示"记忆: N 条"

### Step 7：测试（pytest）
- `test_memory_consolidate.py`：提取/只沉淀 user/跨会话召回/疑问句过滤
- `test_chunker.py`：空文本/多块/段落边界/overlap
- `test_knowledge_search.py`：建库+检索（假 embedding）+ 线程安全回归（P-018）
- `test_embedding_registry.py`：已知维度/本地判定/探针兜底

## 6. 参考原版读法（学习点）

1. **记忆 = 可复用事实，不是对话全文**：沉淀做提取，召回才有效（原版分层 L2/L3/L4）
2. **RAG 三步**：分块 → 向量化 → 余弦召回；维度一致性是前提
3. **向量模型可切换**：全走 OpenAI 兼容协议 + 配置判定（vendor/模型形态），一个实现通吃
4. **SQLite 线程本地连接**：LangGraph 工具在后台线程跑 SQL，连接按线程建（P-018 教训）

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 规则提取漏事实/误提取 | 疑问句过滤 + 只沉淀 user；M5 学原版 LLM 抽取 |
| embedding 维度不一致 | 已知维度表 + detect_embedding_dim 探针；验收排查表已列 |
| 工具线程 SQL 报错 | BaseRepository db_path 模式（线程本地连接，P-018 已修+测试回归） |
| 记忆注入 token 成本 | recall 限制 10 条 + 注入格式紧凑 |
