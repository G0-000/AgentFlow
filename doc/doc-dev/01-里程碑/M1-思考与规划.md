# M1 思考与规划（分文档）

## 1. 先读原版：四个关键发现

### 1.1 `agents/thread_state.py` → "状态先行"

原版 ThreadState 继承 `langchain.agents.AgentState`（自带 messages + 追加 reducer），
再扩展 sandbox / thread_data / ui_messages 等字段，并定义 reducer 合并函数：

```python
class ThreadState(AgentState):
    sandbox: NotRequired[SandboxState | None]
    thread_data: NotRequired[ThreadDataState | None]
    # ...（ui_messages 是摘要前的展示副本）
```

**结论**：图的一切信息都在这一个 dict 里流转——数据长什么样，逻辑就怎么写。

### 1.2 `agents/lead_agent/agent.py` → "心脏"

`make_lead_agent` 有 **1700 行**：`create_agent(llm, tools)` + **30+ 个中间件**
（Clarification / Memory / Title / Transcript / TokenUsage / SubagentLimit / ToolApproval...）。

**结论**：原版复杂在"中间件横切 + 工具目录 + 多域协作"，骨架其实只有三层：
`create_agent(llm, tools) + ThreadState(状态) + checkpointer(持久化)`。M1 只搭骨架。

### 1.3 `config/`（36 文件）与 `persistence/`（60 文件）→ "地基"

- config：yaml → 类型化对象，模型配置独立成模块（models_yaml 等）
- persistence：SQLite 唯一属主，db / schema / data_layout / bootstrap + 各 repo

## 2. 结构规划原则：目录照搬，文件砍 95%

| 原版 | M1 保留 | 理由 |
|---|---|---|
| config/ 36 文件 | 4 个 | 只留 yaml 加载链路必需 |
| models/ 14 文件 | 2 个 | factory + openai 适配 |
| persistence/ 60 文件 | 6 个 | db/schema/bootstrap/timestamps/repo 骨架 |
| agents/checkpointer/ 5 文件 | 2 个 | provider + 对齐原版入口名 |
| agents/lead_agent/ 12+ 文件 | 2 个 | agent.py + prompt.py（时间注入，原版无独立时间工具） |

**原则**：目录层级和命名照原版（对照学习零偏差），文件数按里程碑裁剪（M1 不需要的宁可不建）。

## 3. 最小形态：agent.py 的精华

M1 的 agent 工厂核心逻辑：

```python
def make_lead_agent(model, checkpointer, tools=None, system_prompt=None):
    agent = create_agent(
        model=model,
        tools=tools or [],          # M1 空；M2 传工具目录（原版 tool_catalog）
        checkpointer=checkpointer,  # 会话持久化
        system_prompt=system_prompt or build_lead_agent_system_prompt(),
    )                               # 0 工具，0 中间件
    return agent                    # CompiledStateGraph
```
- 时间不设工具：由 `prompt.py` 注入 system prompt（原版真实做法，见 [agents域](../04-模块实现/agents域.md)）

调用方式（验证"会话可恢复"的关键）：

```python
config = {"configurable": {"thread_id": thread_id}}
for chunk in agent.stream({"messages": [("user", user)]}, config=config):
    ...   # .stream() 是 M2 流式输出的基础
```

## 4. 关键坑：依赖版本冲突（摘要）

`ImportError: cannot import name 'ExecutionInfo' from 'langgraph.runtime'`

- 根因：pyproject 约束过宽 → uv 装到 prebuilt 1.0.13（需新 API），langgraph 锁 1.0.9
- 修复：查原版 uv.lock → 原版锁 prebuilt **1.0.8** → 对齐解决
- **教训：原版 lock 是版本生态的权威答案，遇冲突先查它**
- 详录：[03-决策记录/ADR-002](../03-决策记录/ADR-002-依赖版本对齐原版.md)
