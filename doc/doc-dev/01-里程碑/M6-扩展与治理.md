## 2. 原版纠偏记录（必读——对齐表错位清单）

验收清单里"对齐原版 mcp/、community/、authz/、observability/、webui/"的字面对齐，
经源码核实有以下错位（M6 照此纠偏，不整包照搬）：

### 纠偏 1：原版 mcp/ 是"外部 MCP 服务器接入层"，不是 MCP 协议实现

原版 `evoflow/mcp/` 13 文件 = 配置加载（config_io/status/market）+ 客户端（client.py 79 行，
基于 langchain-mcp-adapters 的 MultiServerMCPClient）+ 工具桥接（tools.py 366 行）+
**大量外围**（server.py 324 行 MCP 服务器本体 / oauth.py / cache.py / native_prompt.py /
prompt_section.py / binding.py / cli_ops.py / market.py）。

**M6 学什么**：`client.py`（build_server_params：stdio/sse/http 三传输参数构建）+
`tools.py` 裁剪版（配置加载 + 归一化 + load_mcp_tools 同步桥接）。
**砍什么**：server/oauth/cache/market/prompt_section/binding/cli_ops/native_prompt/status
（9 个外围文件不学——M6 是"接入外部 MCP"，不是"自建 MCP 服务器"）。

### 纠偏 2：原版 community/ 是三大集成域，M6 只学"搜索"

原版 `evoflow/community/` 三块：
- `web/`（搜索：provider ABC + registry + 7 个 provider，ddgs 免费无 key）
- `media_generation/`（媒体生成：Kling/即梦/火山 TTS 等，重）
- `web_fetch/` + `firecrawl/`（网页抓取/爬虫）

**M6 学什么**：`web/` 的 provider.py（ABC：name/is_available/search）+ registry.py
（register/list/get/resolve_search_backend）+ `providers/ddgs.py`（免费无 key，符合测试纪律）。
**砍什么**：media_generation（媒体生成整个域）、web_fetch/firecrawl（抓取域）——
验收点 2 只要"1 个第三方集成（搜索）"，媒体生成留待后续需求。

### 纠偏 3：原版 authz/ 是"主体/ACL/可见性"大体系，M6 只学"JWT 鉴权拦截"

原版 `evoflow/authz/` 19 文件 = principals（658 行主体体系）+ acl_store/scope/groups/
membership/session_ownership/workspace_visibility（ACL 与可见性）+ http_guard（472 行
HTTP 守卫，20 个 require_*_visible 函数）+ admin_grants/skill_roots 等。

**M6 学什么**：`http_guard.py` 的最小语义（"无有效 JWT → 拒绝"的守卫模式）。
**砍什么**：principals/acl_store/scope/groups/membership/session_ownership/
workspace_visibility/resource_visibility/admin_grants/skill_roots 等 17 个文件——
"主体-ACL-组织可见性"体系属于 **M7 组织级能力**（collab/），M6 只做"登录鉴权 401/通过"。

### 纠偏 4：原版 observability/ 是 27 文件观测全家桶，M6 只学"最小 trace 链路"

原版 `evoflow/observability/` 27 文件 = recorder（404 行记录器）+ sqlite_store（885 行
8 张表）+ queries（2036 行查询）+ dashboard/latency_waterfall/agent_trace_load（展示层）
+ cache_metrics/thinking_context 等（模型层指标）。

**M6 学什么**：`tables.py`（表名常量）+ `sqlite_store` 的**最小子集**（runs + trace_events
2 张表：insert + 按 run 查询）+ `recorder.py` 的最小语义（fire-and-forget 写库）。
**砍什么**：dashboard/latency_waterfall/agent_trace_load（展示层）、queries 大部
（2036 行只留 get_run 语义）、cache_metrics/thinking_context/compaction_*（指标与文件治理）。

### 纠偏 5：原版 webui/ 学 auth.py + middleware.py，砍 OIDC

原版 `evoflow/webui/` 6 文件 = auth.py（731 行：PBKDF2 密码 + PyJWT 签发/校验 + admin
用户管理 + QR token）+ middleware.py（190 行：BaseHTTPMiddleware 拦截，public path
白名单 + token 提取 + 401 JSON/302 重定向）+ static.py + oidc.py/oidc_config.py。

**M6 学什么**：`auth.py` 的 hash_password/verify_password（PBKDF2-HMAC-SHA256，
标准库实现）+ generate_jwt/verify_jwt（PyJWT）+ `middleware.py` 的守卫语义
（public path 放行 / 无有效 token → 401）。
**砍什么**：oidc（SSO 扩展，M6 不做）、static.py（静态服务）、admin 用户管理
（get_or_create_admin_user 等 10 个函数，M6 用配置 secret 直签）。

## 3. 决策记录（D1-D7）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 依赖追加 3 个：`langchain-mcp-adapters>=0.1.0`、`ddgs>=9.10.0`、`pyjwt>=2.8.0` | M6 三个能力的地基（MCP 客户端/免费搜索/JWT），原版 pyproject 已默认安装同款 |
| D2 | MCP 配置挂 `config.yaml` 的 `mcp_servers` 段（新建 `config/mcp_config.py`） | agentflow 配置哲学 = config.yaml 单一来源；不学原版 SQLite 配置表（M6 砍） |
| D3 | `mcp/` 只建 client.py + tools.py + `__init__.py` 3 文件 | 见纠偏 1：只做"接入"，不做"服务端" |
| D4 | `community/` 只建 web/ 搜索域 3 文件 | 见纠偏 2：验收点 2 只要搜索 |
| D5 | `authz/` 只建 http_guard.py（纯函数守卫）+ `__init__.py`；JWT 签发/校验放 `webui/auth.py`（对齐原版归属） | 见纠偏 3/5：登录鉴权是 webui 的 JWT + authz 的守卫两层 |
| D6 | `observability/` 只建 tables.py + store.py + recorder.py 3 文件（2 张表：runs + trace_events） | 见纠偏 4：最小 trace 链路可查即可 |
| D7 | webui/ 只建 auth.py + middleware.py（纯逻辑，不引入 Starlette） | agentflow 是 CLI 为主；401 语义用纯函数实现可测（不绑定 HTTP 框架） |

## 4. 实现计划（5 包文件清单）

```text
agentflow/
├── config/
│   └── mcp_config.py          # D2：McpServerConfig + load_mcp_servers（stdio/sse/http）
├── mcp/                       # D3：MCP 外部服务器接入
│   ├── __init__.py
│   ├── client.py              # build_server_params + build_servers_config（学原版 79 行）
│   └── tools.py               # load_mcp_tools：配置 → MultiServerMCPClient → BaseTool[] 同步桥接
├── community/web/             # D4：第三方搜索集成
│   ├── __init__.py
│   ├── provider.py            # WebSearchProvider ABC（name/is_available/search）
│   ├── registry.py            # register/list/get/resolve_search_backend
│   └── providers/
│       ├── __init__.py
│       └── ddgs.py            # DuckDuckGo 免费搜索（无 key）
├── authz/                     # D5：鉴权守卫
│   ├── __init__.py
│   └── http_guard.py          # resolve_auth_from_headers + require_api_auth（401 语义）
├── observability/             # D6：最小 trace
│   ├── __init__.py
│   ├── tables.py              # 表名常量（runs + trace_events）
│   ├── store.py               # ObsTraceStore：建表/insert_run/insert_event/get_run
│   └── recorder.py            # ObservabilityRecorder：fire-and-forget 写库
└── webui/                     # D7：登录鉴权
    ├── __init__.py
    ├── auth.py                # hash_password/verify_password + generate_jwt/verify_jwt
    └── middleware.py          # WebuiAuthGuard：public path + token 校验 + 401（纯逻辑）
```
