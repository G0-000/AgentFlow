# M4 —— 子代理 + 沙箱

> **一句话目标**：让主 Agent 从"自己干"升级到"派人干"——
> 把可拆分的任务拆给多个子代理**并行执行**（≤3），结果**回传汇总**；
> 子代理的所有宿主操作（终端/文件）都必须在**沙箱**里进行，
> 越界访问被拦截并全程**审计**。
> 前置：M3 验收 5/5 已过（记忆 + 知识库检索）。

## 1. M4 做什么（用户视角）

| 能力 | 之前（M3） | 之后（M4） |
|---|---|---|
| 干活方式 | 主 Agent 串行做一切 | **派人并行**：说"同时总结 A 和 B 两个文件"→ 派 2 个子代理并行 |
| 并行控制 | 无 | 派 5 个任务 → 实际并行 ≤3，其余排队（ThreadPoolExecutor 天然排队） |
| 宿主安全 | 无沙箱概念 | **目录沙箱**：终端/文件操作落在项目 `.sandbox/` 内，写 `/etc` 等宿主路径被拦 |
| 可追溯 | 无 | **审计表**：每次沙箱操作（放行/拦截）落库，可查"谁对什么做了什么" |

### 3.1 M4 完整调用链（简易流程图：文件 / 函数 / 参数 / 输出）

> 调用顺序：入口 → 派发 → 并行执行 → 工具 → 沙箱 → 审计。
> 每层标注：**文件** · `函数(参数)` → 输出（签名核对自源码，2026-10-01 检查轮）。

```text
【① 入口】cli/main.py
  main()
  ├─ 装配: configure_dispatch_service(tools, model)          ← dispatch_subagents 句柄
  │        set_sandbox_provider(LocalSandboxProvider(项目/.sandbox))   ← 沙箱单例
  │        configure_terminal_audit(repo) + configure_file_audit(repo) ← 审计句柄
  ├─ make_lead_agent(model, checkpointer, tools[9], middlewares, system_prompt)
  │     → create_agent(...) → 主 Agent（含 dispatch_subagents 工具）
  └─ agent.invoke({"messages": [...]})                       → 对话开始
        │
        ▼  模型判断任务可拆 → 调 dispatch_subagents
【② 派发】tools/builtins/dispatch_tool.py
  dispatch_subagents(tasks: list[str], subagent: str, max_parallel: int = 3) → str
  ├─ 校验: 1 ≤ len(tasks) ≤ 10 · subagent 已知 · 服务已配置（否则友好提示，不炸模型循环）
  ├─ get_subagent_config(subagent)    → registry.py 查表 → SubagentConfig
  │                                    （name/system_prompt/tools/白黑名单）
  └─ SubagentExecutor(config, tools, model).dispatch_parallel(tasks, max_parallel)
        │
        ▼
【③ 执行引擎】subagents/executor.py — SubagentExecutor
  __init__(config, tools, model):
    _filter_tools(父级9, config.tools, config.disallowed_tools) → self.tools
    （general-purpose 得 7 个；白名单∩黑名单，黑名单防递归派发）
  dispatch_parallel(tasks, max_parallel=3) → list[SubagentResult]
    workers = max(1, min(max_parallel, 3))   ← 硬上限双保险
    ThreadPoolExecutor(max_workers=workers)  ← 派 5 只 3 并发，其余排队
    每任务 submit(self.run, t)
  run(task, timeout_seconds=None) → SubagentResult
    ├─ 单线程池 → _run_sync(task)
    │    ├─ _build_agent() → create_agent(model, self.tools, system_prompt)   # 无 checkpointer
    │    ├─ agent.invoke({"messages": [{"role":"user","content": task}]})
    │    └─ _extract_final_ai_text(response) → AIMessage 文本 str
    └─ 超时 → TIMED_OUT（shutdown(wait=False) 及时返回，底层线程进程回收）
  [f.result() for f in futures]               ← 按输入顺序回传（不是完成顺序）
        │
        ▼  子代理模型调工具
【④ 工具层】tools/builtins/terminal_tool.py + file_tools.py
  terminal_run(command: str) → str
  read_file(path: str) → str
  write_file(path: str, content: str, append: bool = False) → str
  ├─ sandbox = get_sandbox_provider().get(get_sandbox_provider().acquire())
  │   判空 → "（沙箱未配置）"
  ├─ 执行 → LocalSandbox.execute_command / read_file / write_file
  ├─ except SandboxError → "（沙箱拦截）…" + 审计 allowed=0
  └─ 成功 → 审计 allowed=1
        │
        ▼
【⑤ 沙箱】sandbox/local.py — LocalSandbox
  _resolve(path) → Path     ← 所有文件操作的统一前置闸
    expanduser → 相对路径拼 root → resolve() 规范化 → 前缀校验
    ├─ 越界 → raise SandboxPermissionError
    └─ 合法 → 返回真实路径
  execute_command(command, timeout=30) → str
    subprocess(cwd=root, shell=True, timeout)
    ├─ 超时 / 非零退出码 → SandboxCommandError
    └─ 成功 → 输出文本（stdout+stderr）
        │
        ▼
【⑥ 审计】persistence/sandbox_audit_repositories.py
  SandboxAuditRepository(conn).record(action, target, allowed, reason, subagent_name) → None
  → INSERT sandbox_audit（allowed: 1=放行 0=拦截）；CLI 启动打印审计条数
```

## 6. 关键知识点（M4 归档）

1. **为什么子代理并行 ≤3**：验收清单硬约束（原版 MAX_CONCURRENT_SUBAGENTS=5，AgentFlow 收紧到 3）。实现 = ThreadPoolExecutor(max_workers=3) 天然排队，第 4 个任务等空位，不需要自己写信号量。
2. **为什么子代理默认不能派发**：disallowed_tools 默认排除 dispatch_subagents——子代理再派子代理会无限嵌套。黑名单是默认安全边界。
3. **沙箱越界怎么拦**：路径必须 resolve()（软链/`..` 都规范化）后落在 root 内。用 normpath 会被软链绕过——resolve() 是安全闸的关键。
4. **为什么审计用 0/1 整数**：SQLite 无布尔类型，allowed INTEGER 0/1 直读。
5. **NoopSandbox 为什么不"透传"**：fail-closed 安全默认——桌面没配沙箱时宁可拒绝宿主操作，不让子代理静默跑在宿主上。
6. **TIMED_OUT 为什么不重试**：超时重试只会再超时（同样的慢）；只对 FAILED（模型调用异常）重试。

## 7. 已知边界（M5 再学）

- execute_command 无 OS 级进程 jail：命令内 `cd /etc && …` 可逃逸 cwd（文件路径隔离是完整的，命令逃逸防护留 M5 execution security）
- 子代理不挂 checkpointer：一次执行不持久化（M5 长任务再学）
- dispatch 工具未配置模型时返回友好提示（不炸模型循环）
