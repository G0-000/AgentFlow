# 全流程步骤（M0 → M8 逐步执行清单）

> 每个里程碑：**做什么 → 产物 → 验收入口**。接手 AI 按此推进，每步完成后更新对应验收清单状态。

## M0 — 环境搭建 ✅
1. 装 uv / pnpm（macOS：curl 装 uv，npm -g 装 pnpm）
2. 建双包 workspace（backend + packages/harness）
3. `uv sync` 通过，.venv 生成
- **产物**：两个 pyproject.toml + uv.lock + config.yaml
- **验收**：[M0-验收清单](../05-验收体系/M0-验收清单.md)

## M1 — 最小 Agent 🟡
1. 读原版：thread_state / lead_agent.agent / config / persistence
2. 规划目录（config 4 + models 2 + persistence 6 + agents 5 + tools 2 + cli 2）
3. 写 20 个文件 → `uv sync` → 修依赖冲突（prebuilt 1.0.8）
4. `.env` 填 key → `uv run agentflow` 跑通对话 + `--thread` 持久化
- **产物**：`agentflow/` 全部代码 + `data/agentflow.db`
- **验收**：[M1-验收清单](../05-验收体系/M1-验收清单.md)

## M2 — 工具目录 + 流式 ⏳
1. 读原版：tool_catalog / tools.py / 3 个 builtins / tool_result_store / 2 中间件
2. 写 tool_catalog.py（注册/schema/分组）+ 5 个内置工具
3. 挂 2 个中间件（thread_data / title）到 make_lead_agent
4. CLI 流式输出（agent.stream 逐块打印）
- **产物**：tools/ 完整化 + agents/middlewares/ 起步
- **验收**：[M2-验收清单](../05-验收体系/M2-验收清单.md)

## M3 — 记忆与知识 ⏳
1. 读原版：memory/facade+consolidate / knowledge/service+chunker / embedding/registry / skills
2. 写记忆沉淀与注入（persistence 加表）
3. 写知识库：分块 → 向量 → 检索；embedding 云端/本地可切
- **验收**：[M3-验收清单](../05-验收体系/M3-验收清单.md)

## M4 — 子代理 + 沙箱 ⏳
1. 读原版：subagents（registry/executor/builtins）+ sandbox
2. 写子代理注册与并行执行（≤3）
3. 写沙箱抽象 + 本地提供方 + 审计表
- **验收**：[M4-验收清单](../05-验收体系/M4-验收清单.md)

## M5 — 长任务 ⏳
1. 读原版：plans / goal（graph+runtime）/ collab.execution_lifecycle / scheduler / proactive / automation
2. 写 Plan → Goal 闭环（计划/执行/恢复/汇总）
3. 写定时任务
- **验收**：[M5-验收清单](../05-验收体系/M5-验收清单.md)

## M6 — 扩展与治理 ⏳
1. 读原版：mcp / community / authz / observability / webui
2. 接 1 个 MCP 服务器 + 1 个搜索集成
3. 写 JWT 鉴权 + 链路追踪
- **验收**：[M6-验收清单](../05-验收体系/M6-验收清单.md)

## M7 — 应用层 API + IM ⏳
1. 读原版：app/gateway（app.py + routers/models·runs·threads）+ channels/feishu
2. 建 `backend/app/`（应用层开始）
3. 写 REST/SSE API + 飞书渠道
4. **模型配置迁 SQLite**（学原版进化，API 可管理）
- **验收**：[M7-验收清单](../05-验收体系/M7-验收清单.md)

## M8 — 前端 ⏳
1. 读原版：evopanel（chat-react / models / api-client / modal）
2. `pnpm install` 建 evopanel 工程
3. 写聊天页 + 模型设置页，串通全链路
- **验收**：[M8-验收清单](../05-验收体系/M8-验收清单.md)
