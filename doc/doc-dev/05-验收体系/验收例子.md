# 验收例子（每个里程碑的"输入 → 预期输出"示例）

> 目的：验收不能只靠标准，要有**可复现的例子**——接手 AI 照着跑，看到预期输出即通过。
> 状态列：✅ 已验证 / 🟡 待验 / ⏳ 未开始。

## M0 — 环境（✅ 示例）

```bash
$ uv --version
uv 0.12.19 ...
$ cd backend && uv sync
# 无报错，出现: Building agentflow-harness @ file://.../packages/harness
```

## M1 — 最小 Agent（🟡 示例）

**验收例 1：真实对话 + 时间感知**

```
$ uv run agentflow
会话 ID: a1b2c3d4e5f6
你 > 今天几号？
Agent > 今天是 2026 年 9 月 28 日（周一）...
```

通过标准：回复里出现**当天真实日期**——来源是 `prompt.py` 把当前时间
注入 system prompt（原版做法，非工具调用；别再用独立 datetime 工具）。

**验收例 2：会话持久化**

```
# 第一次（记下 ID: a1b2c3d4e5f6）
你 > 我叫小王
你 > exit

# 第二次复用同一 ID
$ uv run agentflow --thread a1b2c3d4e5f6
你 > 我叫什么？
Agent > 你刚才说叫小王
```

通过标准：新进程记得旧对话（checkpoint 生效）。

## M2 — 工具+流式（⏳ 示例）

```
你 > 搜索一下"LangGraph 是什么"（假设已挂搜索工具）
# 预期：先输出"正在搜索..."（工具调用中），再逐块输出搜索结果总结
```

通过标准：输出**分多块**出现（流式），且最后回答引用了搜索结果。

## M3 — 记忆知识（⏳ 示例）

```
会话A：你 > 记住：我的邮箱是 abc@example.com
新会话B：你 > 我的邮箱是多少？
# 预期：B 直接答出 abc@example.com（跨会话记忆）

知识库导入 FAQ 后：你 > 退款政策是什么？
# 预期：回答内容来自知识库检索结果
```

## M4 — 子代理（⏳ 示例）

```
你 > 同时帮我总结这两个文件：A.py 和 B.py 各自的作用
# 预期：两个子代理并行执行，最终汇总两段总结
```

## M5 — 长任务（⏳ 示例）

```

# 预期：先出计划（3 章步骤）→ 逐步执行 → 中断后 --thread 恢复 → 最终汇总
```
