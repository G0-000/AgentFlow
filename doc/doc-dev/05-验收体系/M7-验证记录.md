## 7. 遗留观察（不阻塞验收）

- run 注册表为进程内 dict：多副本/重启后 run_id 失效（M7 单进程够用，M8 再评估持久化）。
- 默认 runner 为缓冲式（invoke 完才出块）；真逐 token 流式可在 `_build_default_runner` 增强。
- 飞书真实端到端（机器人收/发消息）需在飞书开放平台创建自建应用、配置事件订阅/长连接并注入 app_id/app_secret，本次未联网实测，验收以离线管线用例为准。
- M0-M6 审计遗留低优先级项（不阻塞本里程碑，见回归状态文档 §7）：M6 四域接线（属 M8）、`goal_loop.start()` 首转 invoke 容错、observability recorder docstring、webui 静态白名单、drain 循环容错、文档缺口（2 份 lite 文档符号 / 12 个 tests 无逐文件文档 / 9 份缺章节）等。
- EvoFlow 周更对齐：10-10 后原版提交链均为 Rust（evopanel）编译修复，Python 核心零改动，无需本里程碑对齐（依据 `M0-M6-全面审计报告.md` §⑤）。
