# M4 验收清单

> **怎么验收 M4**：子代理 + 沙箱。状态：⏳ 未开始（清单先行）。

## 功能需求（用户视角：Agent 会"派人干活"）

1. 主 Agent 能把任务**拆给子代理**并行执行（如"查 A + 写 B 同时进行"）
2. 子代理结果**回传汇总**给主 Agent 继续决策
3. 子代理在**沙箱**里执行（不能乱碰宿主）
4. 并行数量受控（原版默认 ≤3）

## 代码需求（对齐原版结构）

| 要求 | 对照原版 |
|---|---|
| `subagents/registry.py`（子代理注册） | `evoflow/subagents/registry.py` |
| `subagents/executor.py`（后台执行/生命周期） | `evoflow/subagents/executor.py` |
| `subagents/builtins/`（内置子代理类型） | `evoflow/subagents/builtins/` |
| `sandbox/`（抽象接口 + 本地提供方） | `evoflow/sandbox/` |
| 子代理工具：`terminal_*` / `read_file` 等 | `evoflow/tools/host_direct/` |
| persistence：sandbox_audit 表 | 原版 `sandbox_audit_repositories.py` |

## 验收点

| # | 验收点 | 怎么验 | 通过标准 | 状态 |
|---|---|---|---|---|
| 1 | 子代理注册 | CLI 触发需要并行的任务 | 任务被拆给多个子代理 | ⏳ |
| 2 | 并行控制 | 同时派 5 个任务 | 实际并行 ≤3，排队执行 | ⏳ |
| 3 | 结果回传 | 问"总结 A 和 B 两个文件" | 主 Agent 拿到两个子代理结果并汇总 | ⏳ |
| 4 | 沙箱隔离 | 子代理尝试写宿主系统目录 | 被拦截/隔离（沙箱内可写） | ⏳ |
| 5 | 回归 M1-M3 | 重跑 M1/M2/M3 验收清单 | 全部 ✅ | ⏳ |

## 验收不过排查

| 现象 | 处理 |
|---|---|
| 不派子代理 | 子代理工具是否注册给主 Agent；任务是否满足拆解条件 |
| 并行超限 | executor 的并发上限配置 |
| 沙箱失效 | 本地提供方实现；抽象接口是否所有工具都走 |
