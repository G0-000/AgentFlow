## 功能需求（用户视角：Agent 会"派人干活"）

1. 主 Agent 能把任务**拆给子代理**并行执行（如"查 A + 写 B 同时进行"）
2. 子代理结果**回传汇总**给主 Agent 继续决策
3. 子代理在**沙箱**里执行（不能乱碰宿主）
4. 并行数量受控（原版默认 ≤3）

**代码侧**（批判性复查发现 2 个真实 bug，已修复 + 2 个新测试，62 → 64 passed）：
1. **executor.run() 超时失效**：`with ThreadPoolExecutor` 退出时 `shutdown(wait=True)` 会等悬挂线程跑完——超时后调用方仍阻塞到任务实际结束（SlowAgent 3s + timeout 1s → 实际等 3s）。修复：超时路径 `pool.shutdown(wait=False)` 及时返回（底层线程由进程退出回收，best-effort 语义不变）。新增 `test_timeout_returns_promptly` 断言 <2.5s 返回。
2. **local.list_dir depth 语义失效**：原 `rglob("*")` 是无限递归（depth>=2 时 max_depth 不生效）。修复：`os.walk` 按层遍历，`level >= depth` 时 `dirs[:] = []` 停止下钻。新增 `test_local_sandbox_list_dir_depth` 断言 depth=1/2/3 层级语义。
3. 附带修正：write_file 写入前自动建父目录（`p.parent.mkdir`）——工具写 `a/b.txt` 不必先建目录，更符合 Agent 工具调用习惯；清理 list_dir 内残留的 `import os as _os`。
