## 依赖冲突修复记录（重要教训）

**现象**：import agent 报 `ImportError: cannot import name 'ExecutionInfo' from 'langgraph.runtime'`

**根因链**：
```
约束 langgraph>=1.0.6,<1.0.10  → 装 1.0.9
langgraph 1.0.9 依赖 prebuilt>=1.0.8,<1.1.0（过宽）→ 装 1.0.13
prebuilt 1.0.13 需要 langgraph.runtime.ExecutionInfo（1.0.9 没有）→ 运行时炸
```

**修复**：查原版 `EvoFlow/backend/uv.lock` → 原版锁 `langgraph-prebuilt==1.0.8` → 对齐 → 解决。

完整记录见 [ADR-002](../03-决策记录/ADR-002-依赖版本对齐原版.md)。
