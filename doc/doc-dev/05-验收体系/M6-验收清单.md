# M6 验收清单

> **怎么验收 M6**：扩展（MCP/社区集成）+ 治理（鉴权/可观测基础能力）。状态：✅ 已完成（2026-10-05，5/5 通过，`uv run pytest -q` = 126 passed）。

## 功能需求（用户视角：系统可扩展、可管控、可观测）

1. 能通过客户端从 **MCP 服务器发现工具**；主 Agent 工具目录接线不属于 M6 已完成范围
2. 至少有 1 个第三方搜索 provider 能返回结构化结果；自动化验收使用 mock，不验证真实网络
3. 提供可复用的 JWT 签发/校验与纯逻辑守卫；尚未挂到实际 HTTP 路由
4. **可观测基础能力**：显式写入 run/span 后，可按 run_id 查询记录与延迟。M6 尚未将 recorder 自动接入 Agent 对话循环。
