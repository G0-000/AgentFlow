# M5 验收清单

> **怎么验收 M5**：长任务引擎（Plan/Goal）+ 定时调度。状态：✅ 已完成（2026-10-02，6/6 通过，`uv run pytest -q` = 86 passed）。

## 功能需求（用户视角：Agent 会"持续干活"）

1. 复杂任务先**出计划**（Plan：步骤清单），再逐步执行
2. 长任务**后台运行**，中断后**可恢复**（不是一次对话的事）
3. 每步结果汇总成**最终报告**
4. 支持**定时任务**（如"每天 9 点检查某网站"）
