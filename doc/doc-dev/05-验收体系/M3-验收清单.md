# M3 验收清单

> **怎么验收 M3**：记忆沉淀 + 知识库检索。状态：⏳ 未开始（清单先行）。

## 功能需求（用户视角：Agent 会"记住"和"查资料"）

1. 对话中用户说的**重要事实被记住**（"我叫小王"→ 下次直接称呼）
2. 记忆能**沉淀入库**（不是每次临时拼，而是写进持久化）
3. 知识库：文档**分块 → 向量化 → 检索**，结果注入上下文
4. 至少 1 个知识库可建、可查（文本/代码片段）

## 代码需求（对齐原版结构）

| 要求 | 对照原版 |
|---|---|
| `memory/facade.py`（记忆总入口）+ `consolidate.py`（沉淀） | `evoflow/memory/facade.py`、`consolidate.py` |
| `knowledge/service.py`（知识库总入口） | `evoflow/knowledge/service.py` |

| `skills/`（SKILL.md 发现/加载/注入 prompt） | `evoflow/skills/` |
| persistence 增加 memory/knowledge 表 | 原版 memory_repositories.py 等 |

## 验收点

| # | 验收点 | 怎么验 | 通过标准 | 状态 |
|---|---|---|---|---|
| 1 | 记忆注入 | 对话"我叫小王，喜欢爬虫"→ 新会话问"我叫什么" | 新会话也记得（跨会话） | ⏳ |
| 2 | 知识库建库 | CLI/脚本建知识库，导入一段文本 | 分块+向量化完成，无报错 | ⏳ |
| 3 | 知识检索 | 问一个只有知识库里有的问题 | Agent 引用检索结果回答 | ⏳ |
| 4 | 向量模型可切换 | 云端 embedding 换本地（LM Studio/Ollama） | 配置驱动切换，代码不动 | ⏳ |
| 5 | 回归 M1+M2 | 重跑 M1/M2 验收清单 | 全部 ✅ | ⏳ |

## 验收不过排查

| 现象 | 处理 |
|---|---|
| 记不住 | memory 中间件是否挂上；consolidate 是否在对话后触发；表是否建 |
| 检索为空 | chunker 是否产出；embedding 维度是否与库一致（bge-small=512 / bge-m3=1024） |
| embedding 不可用 | 云端：vendor 别选 local；本地：OpenAI 兼容地址（见模型选型结论） |
