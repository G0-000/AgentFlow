## 验收点

| # | 验收点 | 怎么验（命令/操作） | 通过标准 | 状态 |
|---|---|---|---|---|
| 1 | 配置加载 | `cd backend && uv run python -c "from agentflow.config.app_config import load_config; c=load_config('/Users/main/AgentFlow/config.yaml'); print(c.models.chat.model)"` | 打印出 `deepseek-chat`（或你的模型名） | ✅ 已过 |
| 2 | SQLite 建表 + repo | `uv run python -c "from agentflow.persistence.bootstrap import init_db; from agentflow.persistence.session_repositories import SessionRepository; conn=init_db(); r=SessionRepository(conn); r.create('t1','测试'); print(r.get('t1'))"` | 打印出会话 dict，`data/agentflow.db` 生成 | ✅ 已过 |
| 3 | Agent 构建 | `uv run python -c "from agentflow.agents.lead_agent.agent import make_lead_agent; ..."`（api_key 用占位） | 返回 `CompiledStateGraph`，不报错 | ✅ 已过 |
| 4 | 真实对话 | `uv run agentflow` → 输入"今天几号？" | 回复含今天日期（来源：`prompt.py` 注入 system prompt，原版做法；**没有**独立时间工具） | ✅ 已过（2026-09-28 智谱 GLM-4.7-Flash，实测回复"2026年9月28日"） |
| 5 | 会话持久化 | 对话几句后 `exit` → 记下会话 ID → `uv run agentflow --thread <ID>` → 问"我刚才问了什么？" | Agent 记得之前的对话（检查点生效） | ✅ 已过（2026-09-28 同一 thread 两次调用，第二次正确回顾"你问今天几号，我答2026年9月28日"） |

## 验收不过怎么办

| 现象 | 排查路径 |
|---|---|
| `Missing credentials` | .env 文件名/位置错，或 key 占位没替换 |
| `401 / AuthenticationError` | key 错误/过期 → 平台重新生成 |
| `model not found` | 模型名变了 → 查官方文档 |
| 持久化失败（重开不记得） | 检查 `--thread` 是否传同一 id；`data/agentflow.db` 是否生成 |
