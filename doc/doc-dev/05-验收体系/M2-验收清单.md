# M2 验收清单

> **怎么验收 M2**：工具目录 + 流式输出 + 中间件雏形。状态：✅ 已完成（2026-09-28，21 测试全过）

## 功能需求（用户视角：Agent 能力升级）

1. Agent 能按场景**自动选择工具**（不只是写死的 1 个工具）
2. 工具执行结果能**流式回传**（边想边输出，不用等全部完成）
3. 对话有**自动标题**（会话列表友好）
4. 至少有 5 个可调工具（日期/搜索/知识库/计划/澄清等）

## 代码需求（对齐原版结构）

| 要求 | 对照原版 |
|---|---|
| `tools/tool_catalog.py`（工具注册表：schema/分组/按需加载） | `evoflow/tools/tool_catalog.py`、`tools.py` |
| `tools/builtins/` 至少 5 个 `xxx_tool.py` | `evoflow/tools/builtins/`（45+ 文件） |
| `tools/tool_result_store.py`（工具结果存取） | `evoflow/tools/tool_result_store.py` |
| `agents/middlewares/` 2 个中间件（thread_data / title） | `evoflow/agents/middlewares/`（70+） |
| 流式输出链路（`agent.stream()` 接 SSE/回调） | 原版 `app/gateway` 的 stream 相关（M7 才做网关，M2 先在 CLI 验证） |

## 验收不过排查

| 现象 | 处理 |
|---|---|
| 工具不被调用 | 检查 docstring（模型靠它理解工具）；工具 schema 是否注册进 create_agent |
| 流式没反应 | 确认用 `.stream()` 而非 `.invoke()`；打印每个 chunk 的消息字段 |
| 标题为空 | 中间件顺序问题（title 中间件要在消息写入后执行） |
