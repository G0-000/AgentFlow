# M7 验收清单

> **怎么验收 M7**：应用层（Gateway API）+ IM 渠道。状态：⏳ 未开始（清单先行）。

## 功能需求（用户视角：外部世界能触达 Agent）

1. **REST/SSE API**：外部程序能发起对话、拿结果（流式）
2. 核心资源有 API：**模型 / 运行(runs) / 会话(threads)**
3. 至少接入 **1 个 IM 渠道**（建议飞书）：IM 里发消息 → Agent 回复
4. 会话/模型可通过 API 管理（不是只能改 yaml）

## 代码需求（对齐原版结构）

| 要求 | 对照原版 |
|---|---|
| `app/gateway/app.py`（应用装配） | `EvoFlow/backend/app/gateway/app.py` |
| `app/gateway/routers/`：models / runs / threads（先 3 个） | 原版 routers/（60+） |
| 流式处理：SSE 规范输出 | 原版 `openai_stream_normalize.py` `sse_ui_normalize.py` |
| `app/channels/feishu.py`（飞书回调→Agent→回复） | 原版 `app/channels/feishu.py` + `feishu_stream_bridge.py` |

| **模型配置迁移 SQLite**（API 可管理，学原版进化） | 原版 model_connections.py / bootstrap 迁移 |

## 验收点

| # | 验收点 | 怎么验 | 通过标准 | 状态 |
|---|---|---|---|---|
| 1 | API 发起对话 | `curl -X POST .../api/runs`（带消息） | 返回 run_id，可查询状态 | ⏳ |
| 2 | SSE 流式 | 用 curl/脚本订阅 SSE | 逐块收到回复内容 | ⏳ |
| 3 | 会话 API | 创建/列出/删除会话 | CRUD 全部可用 | ⏳ |
| 4 | 模型 API | 增改模型（写入 SQLite） | 不重启即可切换模型 | ⏳ |
| 5 | 飞书渠道 | 飞书发消息给机器人 | 收到 Agent 回复 | ⏳ |
| 6 | 回归 M1-M6 | 重跑 M1-M6 验收清单 | 全部 ✅ | ⏳ |

## 验收不过排查

| 现象 | 处理 |
|---|---|
| API 404 | 路由注册顺序；router 前缀 |
| SSE 断开 | 流式编码格式与前端约定；心跳 |
| 飞书不回 | 事件订阅 URL 校验（回调验证）；去重逻辑 |
